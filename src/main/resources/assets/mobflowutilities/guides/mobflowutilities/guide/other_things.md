# Other Things

## Mob Catcher

<RecipeFor id="mob_catcher" />

Catches any non-boss-mob. Shift-right-click a mob catches it, shift-right-clicking an occupied Mob Catcher releases it.

## Giga Tank

<RecipeFor id="gigatank" />

Just a big fluid tank. The Gigatank supports simple bucket interactions. Right-click the tank with an empty bucket to extract one bucket of fluid, or use a bucket containing fluid to insert it.

## Glimmer Lamp

<RecipeFor id="glimmer_lamp" />

A nice-looking light-emitting block. It can be switched on/off using redstone.

## Dark Glass

<RecipeFor id="dark_glass" />

Blocks light (like vanilla tinted glass), and it's wither-proof. Also, nice connected textures.
